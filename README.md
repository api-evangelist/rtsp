# RTSP - Real-Time Streaming Protocol

Real-Time Streaming Protocol (RTSP) is an application-level network protocol designed for controlling streaming media servers. Defined by IETF RFC 2326 (RTSP 1.0) and RFC 7826 (RTSP 2.0), it acts as a network remote control for multimedia servers, enabling on-demand delivery of real-time audio and video data. Widely used in IP cameras, DVR systems, media servers, and live streaming platforms.

**Human URL:** https://datatracker.ietf.org/doc/html/rfc7826
